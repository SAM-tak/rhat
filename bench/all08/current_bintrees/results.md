## Limits

The R^ port uses two i32 child indices per node (8 bytes), rather than
Goose relative references. These runs use statically assigned data stacks, reserved at startup. Each temporary tree rewinds its stack watermark and retains committed pages for reuse. Windows commits up to 1 MiB on page faults.
Runtime bounds checks and OS-backed array storage are included in these measurements.
There is no R^/MSVC row: MSVC does not consume LLVM IR.
All fifteen other workloads are ported; see [current comparisons](../../current/workloads_results.md) and [coverage](../../coverage.md).
Raw samples, checksums, source hashes and build commands are in `results.json`.
