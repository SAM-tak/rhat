# 集約値に別領域の情報を付けた段階の測定

元の全比較実装を再ビルド・再測定し、全48条件は合格した。
[結果](results.md) と [機械判定](verification.json) を当時のまま保持する。

ただし、その後の生成コード検証で LLVM の集約値の分解時にタグが失われる箇所が見つかった。
lru 小サイズのアセンブリはタグなしの pop 展開版と同一であり、この測定の速度差をタグの効果とは主張しない。
親ディレクトリの最新版では、フィールド単位の読み込みへタグを付けて再測定する。

JSON 内の報告パスは当時の元の配置である。測定後、生成物や検証結果を変更せずこのディレクトリへコピーした。
生成物は build/all08-final-workloads と build/all08-final-trees に保持している。
