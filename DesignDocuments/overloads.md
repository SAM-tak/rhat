# 関数・手続きの交差型と演算子定義

トップレベルの一つの `let^` 宣言で、関数・手続きの候補を `&` でつなげられます。
候補は引数個数だけでなく引数型でも区別できます。同じモジュールで同名の自由関数を
後から宣言することはできません。`overload^` はメソッドだけに使います。
`&` による関数本体の連結はトップレベルの宣言専用であり、ローカル束縛や一般の式には使えません。
型の交差は `&` です。交差は合併 `|` より強く結合します。現在の交差型の対象は関数・手続きです。

```rhat
let^read = f^value:i32^ -> i32^{ value+1 }
          & f^value:string^ -> i32^{ 42 }
let^alias:f^i32^ -> i32^; & f^string^ -> i32^; = read
print^(alias(2),alias("text"))
```

候補には `f^`・`p^`・`template^`・`externC^`・`externLLVM^` を混在させられます。
外部関数の署名は従来どおり `;` で終え、その後に `&` を書きます。

関数型は `f^ 引数型, … -> 返り値型;`、手続き型は `p^ … -> 返り値型;` です。
引数がなければ型を並べません。返り値の `-> …` は省略でき、その場合は void です。
末尾の `;` は署名の一部です。`(f^i32^->i32^; & f^string^->i32^;)` のように括弧も使えます。
`ref^` は参照専用であり、交差の `&` と役割を分けています。

## 候補の重なりと解決

候補の順位付けは行いません。宣言時に、型が確定した実引数に対して、同名のどの二つの選択肢も
受け取り可能な型域が重ならないことを検査します。返り値型や `f^` / `p^` の違いは分離条件になりません。

引数個数が異なるか、一つ以上の引数位置で型域が交わらなければ分離できます。
合併型は各選択肢、参照型は参照先の型まで検査します。R^ は公称型を用いるため、
構造体では継承関係とプログラム内の共通派生型を調べます。
型が未確定の引数を分離の根拠にはできません。必要に応じて注釈を付けます。

呼び出しでは、実引数の型全体を受け取れる唯一の選択肢を使います。
`i32^|string^` を二つの選択肢へ実行時に振り分けることはしません。先に `fits^` などで絞り込みます。
通常の関数・メソッド呼び出しでは、未注釈の数値リテラルを各候補の仮引数型で判定します。
共通の期待型がなくても、先に `i32^` や `f64^` に固定しません。
型が確定した引数の適合と、リテラルの適合をすべて満たす候補が一つなら、それを選びます。
引数の記述順には依存しません。整数リテラルは期待する整数型の範囲を検査し、
浮動小数点型を期待する場合は通常の丸め規則で有限値になることを検査します。
小数点を含むリテラルを整数型へ暗黙に変換することはありません。

```rhat
let^min=f^a:f32^,b:f32^ {if^a<b:a el^:b;}
& f^a:i64^,b:i64^ {if^a<b:a el^:b;}
let^text="hello"
print^(min(text.bytes.len,160),min(160,text.bytes.len)) # 両方 i64^
print^(min(f32^(200.0),160)) # f32^
```

複数候補に適合する `min(1,2)` は曖昧エラーです。既定の数値型、幅、宣言順で
候補を順位付けしません。型指定が必要なら `min(i64^(1),2)` のように書きます。

ただし呼び出しに期待型があり、適合する候補のうち返り値型（宣言または推論）がその型と一致するものが
一つだけなら、それを選びます。`let^r:i64^=min(1,2)` は i64^ 版、`let^lens:f32^=math.tan(0.5)` は
f32^ 版です。引数・関数の戻り値・束縛の注釈などが期待型になります。曖昧さを解くだけで、変換はしません。
型が確定した f64^ の引数で `let^y:f32^=math.tan(x)` と書けば f64^ 版を選び、結果の縮小は従来どおりエラーです。
これはリテラルの文脈による型付けであり、型が確定した値の暗黙変換ではありません。
`min(i64^(1),i32^(2))` や、`let^small=2` の後の `min(i64^(1),small)` は不適合です。
単独のリテラル束縛など、期待型を供給する呼び出し候補がない場所の既定型は従来どおりです。

## メソッドと継承

メソッドに選択肢を追加するときは `overload^` を付けます。元の選択肢がない場合や、
既存の選択肢と重なる場合はエラーです。

```rhat
def^ Reader {
    read = f^ self^,value:i32^ ->i32^ { value+1 }
    overload^ read = f^ self^,value:string^ ->i32^ { 42 }
}
def^ Derived : Reader {
    override^ read = f^ self^,value:i32^ ->i32^ { value+10 }
}
```

`override^` は重なる一つの選択肢だけを置き換え、他の選択肢は残します。
引数・返り値・効果・公開制御の契約は既存の R^ の規則どおり維持します。

## 静的に選択される関数値

関数名や無名関数を `let^` に束縛し、引数や返り値として渡せます。
注釈は要求する呼び出し契約を検査し、具体的な宣言と交差の全選択肢は具体化のために保持します。
`value.method` で取り出したメソッドは受け手を捕捉しません。
`let^ call=value.method` の後は `call(ref^ value,argument)` と受け手を明示します。

呼び出し先の宣言はコンパイル時に決まり、LLVM IR では具体化した関数を直接呼び出します。
外側のローカル変数の捕捉、`var^` による呼び出し先の選び替え、宣言情報を消した
関数ポインタのフィールド保存、関数値の配列、実行時条件による異なる関数値の合流には対応しません。

## 演算子定義

演算子は `def^` 内のメソッドとして `op^` で定義します。
演算子の綴りと初期化の `=` は空白で分けます。`op^+=` は `+` の定義にはなりません。

```rhat
def^ Vec {
    self^{x:i32^=0}
    op^+ = f^ self^,rhs:Vec ->Vec { Vec{x=self^.x+rhs.x} }
    overload^ op^+ = f^ self^,rhs:i32^ ->Vec { Vec{x=self^.x+rhs} }
    overload^ op^+ = f^ lhs:i32^,self^ ->Vec { Vec{x=lhs+self^.x} }
    op^- = f^ self^ ->Vec { Vec{x=-self^.x} }
    op^<=> = f^ self^,rhs:Vec ->i32^ { self^.x-rhs.x }
}
```

書ける名前は `+`・`-`・`*`・`/`・`//`・`%`・`**`・`::`・`cross^`・`dot^`・`<=>`・`=` です。
`cross^` は `×`、`dot^` は `⋅` とも書けます。定義と使用のどちらでも同じ演算子へ正規化します。
二項演算子は `self^` ともう一つの引数を取る純粋な `f^` に限ります。
`p^` と `mutable^` は使えません。`-` だけは `self^` 一つで単項演算子も定義できます。
前置 `*` は引き続き dereference であり、単項演算子の定義対象ではありません。

左の受け手の適合する選択肢を探し、なければ右の受け手を探します。
右の受け手として使う定義は `self^` を末尾に置きます。左右の向きは別の選択肢です。
もう一方の引数が `ref^ T` なら、値の被演算子を自動で借用します。
`let^` の値、フィールド、配列要素、関数の返り値、一時値も対象です。
通常の関数引数への自動借用は行いません。
演算子は通常の `f^` に限るため、借用先の変更や `p^` の呼び出しはできません。
参照型に変更権限の修飾子を追加せず、既存の `f^` / `p^` の制限を使います。
自動借用した `let^` や一時値への参照が結果に含まれて外へ逃げる場合は、寿命検査で拒否します。
自動借用を含めて引数の型域が重なる演算子定義も、宣言時に重複として拒否します。

```rhat
def^ F2 {
    self^{x:f32^=0.0,y:f32^=0.0}
    op^- = f^self^,other:ref^Self^ {F2{x=self^.x-other.x,y=self^.y-other.y}}
    op^dot^ = f^self^,other:ref^Self^ {self^.x*other.x+self^.y*other.y}
    square_length = f^self^ {self^ dot^ self^}
}
let^a=F2{x=3.0,y=4.0}
let^b=F2{}
print^((a-b).square_length())
```

`self^` は参照なので、もう一方の引数が値の型なら明示的に `*` で取り出します。
たとえば `op^dot^ = f^ self^,rhs:Vec ->f32^ {...}` を持つ型のメソッドでは、
自分自身との内積を `self^ dot^ *self^` と書きます。
両方の被演算子は左から右に一度ずつ評価します。比較連鎖も中間値を一度だけ評価し、短絡します。
`+=` などの複合代入は対応する二項演算子を使い、その結果を元の保存先へ書き戻します。
演算子が所有配列を返す場合も、通常の関数と同じく束縛先・返却先へ直接構築します。

`op^=` は `bool^` を返し、`=` とその否定の `!=` を定めます。
`op^<=>` は符号付き整数を返し、ゼロとの比較から順序を定めます。
`op^=` に適合する選択肢がなければ、等値比較にも `<=>` を使います。
`<`・`>`・`<=`・`>=`・`!=` を個別に定義することはできません。

数値の既存の組み込み演算は維持します。数値の `<=>` は `i32^` の -1・0・1 を返します。
数値の `//`・`**`、文字列連結などの新しい組み込み処理は追加していません。
これらの綴りは、現時点では利用者定義の演算子がある型で使います。
`**` と `::` は右結合、優先順位は L^ の表に合わせます。
