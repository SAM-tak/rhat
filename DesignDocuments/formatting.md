# ソースの整形

整形エンジンは `src/format.c` に一つ置き、`rhat format` / `rhat format-check` と
LSP の `textDocument/formatting` が共有します。L^ の整形器を基に、R^ 自身の字句・構文解析に接続しています。
VS Code 拡張は標準の LSP 整形機能を使い、別の整形処理を持ちません。

## 利用方法

```powershell
rhat format examples/generic_vec2.rh
rhat format-check examples/generic_vec2.rh
```

`format` はファイルを整形し、変化がない場合は書き込みません。
`format-check` はファイルを変更せず、未整形なら終了コード1を返します。
構文が壊れている入力や、整形によって読み方が変わる入力は変更せず失敗します。
型検査や import の読み込みは不要なので、依存モジュールを取得していないソースも整形できます。

VS Code では「ドキュメントのフォーマット」（Windows は `Shift+Alt+F`）を使用します。
拡張の識別子は `SAMtak.rhat` です。保存時整形は利用者が次のように有効化します。

```json
"[rhat]": {
  "editor.defaultFormatter": "SAMtak.rhat",
  "editor.formatOnSave": true
}
```

LSP は未保存バッファのスナップショットから全文置換の編集を返し、ディスク上のソースには書き込みません。
既に整形済みなら空の編集配列、不正な構文なら `null` を返します。
編集範囲は日本語・補助平面文字を含めて UTF-16 座標で計算します。
処理中の編集やキャンセルは、ほかの問い合わせと同じ要求キューで扱います。

## 綴りと読み方の保持

字句の間の空白・改行・インデントだけを整えます。コメント、文字列、補間文字列の穴、
数値や Unicode 演算子、引用符付き識別子の綴りは、そのまま書き戻します。
複数行の文字列やブロックコメント内部の改行コードも変更しません。

同じパーサーで整形結果を読み直し、字句の種類と元の綴り、および構文解析で得た節の種類と
トークン上の範囲が一致することを確認します。改行が呼び出しや `return^` の読み方を変えた場合も検出します。
整形用の構文記録は要求ごとに回収し、通常のコンパイルでは作りません。

## 整形規則

- 通常は字句間に空白を一つ置きます。呼び出し・添字・メンバ参照・閉じ括弧の前などは詰めます。
- ハット識別子の直後は既定で空白を置きません。`let^ x` は `let^x` になります。
- `<` `>`、`:`、`|` `&`、`..`、構築式の波括弧や一行の `{...}` 内などは、書き手の空白の有無を保ちます。
- 改行位置は原則として保持し、連続した空行は一行にまとめ、字句間の行末空白を除きます。
  行末コメントの前の空白は保持します。
- 括弧と構文の範囲からインデントを決めます。同じ行で開いた範囲は一段として数え、閉じ括弧は開いた行へ戻します。
  `el^`・`when^`・`catch^`・ループの節は、対応する構文の頭に揃えます。
- 複数行のブロックの `{` は指定したスタイルで配置します。構築式や型定義の波括弧は移動しません。
- 長い行は、その行に収まった最も広い括弧の内側で、開き括弧の後・同じ高さのカンマの後・閉じ括弧の前で折ります。
  呼び出しを変えないよう、`(` や `[` の前には改行を加えません。折れない行はそのまま保ちます。

## EditorConfig

対象ファイルから親へ `.editorconfig` を探索し、`root = true` で止まります。近い設定が優先されます。
LSP の `tabSize`・`insertSpaces` は出発点であり、EditorConfig の設定があればそちらを使います。

| 項目 | 値 | 既定 |
| --- | --- | --- |
| `indent_style` | `space` / `tab` | `space` |
| `indent_size` | 数 / `tab` | `4` |
| `tab_width` | 数 | `4` |
| `max_line_length` | 数 / `off` | `100` |
| `end_of_line` | `lf` / `crlf` / `cr` | 入力の最初の改行 |
| `insert_final_newline` | `true` / `false` | `true` |
| `rhat_brace_style` | `same_line` / `next_line` | `same_line` |
| `rhat_space_after_hat` | `true` / `false` | `false` |

glob の `*`・`**`・`?`・`[…]`・`{a,b}`・`{1..3}` と、値の `unset` に対応します。
L^ 固有の項目と区別するため、R^ の固有設定は `rhat_` で始めます。
範囲整形・入力時整形は提供しません。
