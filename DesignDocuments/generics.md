# 型パラメータ・型別名・型定数

`def^Vec2<T>` の型パラメータ、`let^Float2 = Vec2<f32^>` の型別名、
型に属する `ZERO` などの定数を実装しています。

```rhat
def^Vec2<T> {
    self^{ x:T, y:T }
    ZERO = Self^{ x=T.ZERO, y=T.ZERO }
    ONE = Self^{ x=T.ONE, y=T.ONE }
    op^+ = f^self^, other:Self^-> Self^{
        Self^{ x=self^.x+other.x, y=self^.y+other.y }
    }
    op^dot^= f^self^, other:Self^-> T {
        self^.x*other.x + self^.y*other.y
    }
}

let^Float2 = Vec2<f32^>
let^a = Float2{ x=2.0, y=3.0 }
let^b:Vec2<f32^> = a + Float2.ONE
print^(b.x, b.y, a dot^b)
```

## 型定義の具体化

型引数は `<...>` に明示します。複数の型引数、入れ子の具体化、参照型・配列型・合併型も指定できます。
型パラメータはフィールド、引数、返り値、基底型、初期化子、メソッド本体で使えます。
`struct^Box<T> { value:T }` や `def^Result<T> = T | nil^` も同じ規則です。

定義の同一性と型引数の組で具体型を共有します。型別名やインポートの別名は別の具体型を作りません。
`Vec2<f32^>` と `Vec2<i32^>` は異なる公称型です。
具体化ごとに構文木を複製し、型パラメータと `Self^` を置き換えてから、既存の型・効果・寿命・配置の検査を行います。
推論結果やメソッドの具体化キャッシュを、異なる型引数の間で共有しません。
`Self^` は具体化された宣言元の型であり、継承先の最終型には置き換わりません。

メンバや演算の存在は具体化後に検査します。`T.ZERO` を使う定義では、型引数も `ZERO` を提供する必要があります。
数値型だけに限定する制約ではなく、独自の数値型にも同じ規則を適用します。
型引数の不足・過剰・重複するパラメータを診断し、具体化の無限展開を防ぐ上限も設けています。

表記は L^ のホスト型の `<...>` に合わせていますが、R^ は実際に型ごとの配置とコードを生成します。
実行時の型引数オブジェクトや、動的な型消去の表現は追加しません。

## 型の別名と公称型

トップレベルの `let^` は、右辺が型ならコンパイル時の型別名になります。実行時の保存領域は持ちません。

```rhat
let^Float2 = Vec2<f32^>
let^AnotherName = Float2
def^Position : Float2 {}
def^Velocity : Float2 {}
def^Choice = Float2 | nil^
```

`Float2`・`AnotherName`・`Vec2<f32^>` は同じ型です。型注釈、構築式、型メンバの参照、合成元で使えます。
`Position` と `Velocity` は別の公称型で、`Choice` も独立した名前付き合併型です。
`def^Name = Type` は一種類だけを選択肢に持つ公称の合併型であり、型別名にはなりません。

ライブラリでは `public^let^Float2 = Vec2<f32^>` として公開できます。
別のモジュールから同じ具体型を参照しても、元の定義にある具体化を共有します。

## 型に属する定数

`def^` 本体の `NAME = 式` で、右辺が関数・手続き以外なら型に属する定数を宣言します。
インスタンスのフィールドには含まれず、`Float2.ZERO` のように型名から参照します。

- 数値型は組み込みの `ZERO`・`ONE` を持ちます。型はその数値型自身で、値はそれぞれ 0 と 1 です。
- リテラル、その演算、固定サイズの値の構築、他の定数への参照を使えます。
- 定数式は利用箇所へ展開します。受け取った構造体変数を書き換えても、別の利用箇所の定数は変わりません。
- 関数呼び出し・実行時変数の参照・所有領域を持つ値は認めません。構築時の既定フィールド初期化子からの呼び出しも拒否します。
  一般のコンパイル時関数実行を導入する機能ではありません。
- 未使用の定数も、具体化された型について検査します。定数同士の循環、同名の重複、フィールドやメソッドとの名前衝突を診断します。
- `private^` の定数は宣言元の定義からだけ参照できます。公開定数の内部で private フィールドを初期化することは可能です。
- 継承した定数の型は宣言元の型です。`def^ Position : Vec2<f32^> {}` の `Position.ZERO` は `Vec2<f32^>` 型になります。

構築構文は既存の `Type{field=value}` と同じで、`Self^{...}` を使います。`Self^(...)` は導入しません。

## 静的メンバ関数

`def^` 本体の関数・手続きメンバで、第1引数が `self^` でないものは静的メンバです（L^ と同じ）。
受け手を取らず、`Type.name(...)` のように型名から呼びます。

```rhat
def^Vec2<T> {
    self^{ x:T, y:T }
    make = f^x:T, y:T -> Self^{ Self^{ x=x, y=y } }
    distance = f^a:Self^, b:Self^-> T { (a - b).length() }
}

let^a = Float2.make(1.0, 2.0)
let^d = Vec2<f32^>.distance(a, Float2.ONE)
```

- 型別名・具体化した型・モジュール修飾（`v.Float2.make(...)`）から呼べます。
  定義の内側では L^ と同じく `def^.name(...)` で囲んでいる定義のメンバを指します（型定数も `def^.ONE` で読めます）。
  `Self^.name(...)` も同じ意味で受け付けます。
  `T`・`Self^` は型定数と同じく具体化ごとに置き換わります。
- 合成先の型からも呼べます（`def^ Pos : Vec2<i32^> {}` の `Pos.make(1, 2)`）。返り値の型は宣言どおりです。
- `overload^` で引数の異なる静的メンバを並べられます。`private^` は宣言元の定義の中からだけ呼べます。
- 本体の中の再帰は `this^(...)` で書けます。同じ型の別の静的メンバは `def^.name(...)` で呼びます（名前だけでは呼べません）。
- 補完では、値の後ろの `.` にはフィールドとメソッドだけ、型名・`def^` の後ろの `.` には静的メンバと型定数だけを出します。
- 静的メンバとメソッドは、どちらも定義のメンバなので同じ名前空間にあります。同名にはできません（L^ と同じ）。
- 値からの呼び出し（`a.make(...)`）、呼ばずに値として取り出す `Type.make`、`dyn^` 経由の呼び出しはできません。
- `abstract^`・`override^` は付けられません。同じ型の中で静的メンバとメソッドが同じ名前を持つこともできません。

## 現在の範囲

型別名はトップレベルが対象です。関数・ブロック内の型別名、型引数の省略推論、
関数への明示的な型パラメータ宣言、部分具体化、型引数の既定値、制約節、値パラメータは未実装です。
配列長や相対参照の基準になる所有者を `<...>` へ渡す機構も、今回の型パラメータとは別に設計します。

使用例は [examples/generic_vec2.rh](../examples/generic_vec2.rh)、回帰検証は `tests/generics.py` にあります。
