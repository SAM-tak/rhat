# エラー値・伝播・捕捉

## エラーは値

`errordef^` の各種別は独立した公称型です。宣言名は種別の合併型となります。
成功値と同じく、タグ付き共用体の値として返します。ネイティブの例外機構は使いません。

```rhat
errordef^ Error { Invalid, Missing }
let^ read=f^ n:i32^ ->i32^ | Error.Invalid {
    if^ n<0 { return^ error^Error.Invalid{} }
    return^ n
}
```

エラーを返す関数を呼んだだけでは、制御は移りません。`fits^` とナローイング、
値マッチで値として扱うこともできます。

## 前置 `try^`

`try^ expression` は対象を一度だけ評価します。成功ならエラーの選択肢を除いた値を返し、
エラーなら囲む `catch^` 節へ移ります。対応する節がなければ、現在の関数からそのエラーを返します。
エラーを含まない型に対しては、そのままの値となります。

```rhat
let^ increment=f^ n:i32^ {
    return^ try^ read(n)+1
}
```

返り値の型を省略した関数には、伝播するエラーを含めて型を推論します。
明示した返り値型は、処理されないエラーをすべて受け入れる必要があります。
トップレベルから未処理エラーを伝播することはできません。

`try^` は単項演算子と同じ優先順位です。式全体を対象にするときは `try^ (expression)` と書きます。
エラーだけの値に対する `try^` は通常経路へ戻らず、`catch^ try^ it^` のような再送出にも使えます。

## 二項 `catch^`

```rhat
let^ value=read(-1) catch^ 0
let^ selective=read(-1) catch^ if^ it^ fits^ Error.Invalid: 0 el^: try^ it^;
```

左辺を一度だけ評価し、成功ならその値を、エラーなら右辺を評価した値を返します。
右辺は遅延評価され、読み取り専用の `it^` が捕捉したエラーを表します。
外側の焦点は `it^^` で参照できます。左辺にエラーの選択肢がなければ診断します。

優先順位は `??` と同じで、通常の二項演算子より高く、左結合です。
`read(-1) catch^ 2+10` は `(read(-1) catch^ 2)+10` となります。
右辺全体を代替値にするには `read(-1) catch^ (2+10)` と書きます。
右辺は値を作る式です。文を並べる場合や `return^` する場合は節を使います。

## ブロック末尾の `catch^` 節

```rhat
do^{
    let^ value=try^ read(-1)
    print(value)
catch^ Error.Invalid:
    print("invalid")
catch^:
    print("other error")
}
```

`do^`、関数・手続き、`if^`、ループの本体末尾に書きます。
型付きの腕を記述順に調べ、最初に適合した腕だけを実行します。
フィルターにはエラー種別またはその合併型を指定します。
型なしの `catch^:` は一度だけ、最後に置けます。どの腕にも適合しないエラーは外側へ伝播します。

腕内の `it^` は、その腕に適合するエラーの型へ絞り込まれます。
本体内で宣言した変数は腕から参照できず、ブロックの外側にある名前を使います。
腕は自身の節には捕捉されません。腕での `try^` は外側の節または呼び出し元へ伝播します。
その節へ移る可能性がある `try^` が本体になければ診断します。

`if^` の最初の条件は本体の外です。条件の失敗は外側の節へ渡ります。
波括弧内の `elseif^` 条件と各分岐の本体は、その `if^` の節の対象となります。
関数 `f^` の本体・各腕が一つの式だけの場合は、通常の `f^` と同様に暗黙の返却となります。

## ループと保存領域

ループの節は `main^` の後、`last^` / `epilog^` の前に置き、各反復の本体だけを捕捉します。
腕から通常終了すると更新・次の反復へ進みます。`break^` / `next^` / `return^` も使えます。
`prolog^` / `pre^` / `first^` / `last^` / `epilog^` とヘッダー・更新の失敗は、
ループ本体の節を通らず外側へ渡ります。

節への移動とエラー返却の経路では、抜けるスコープの所有領域を逆順に巻き戻します。
初期化途中の所有変数も対象です。呼び出し元の返却先へ構築中に失敗して関数内の節へ移る場合は、
返却先スタックの保存位置を復元してから腕を実行します。
参照寿命検査と、全経路でのデータスタック所有者・回収の対応検証は維持します。

## 現在の範囲

- エラー種別は付随情報なしです。共通の `error^` 型、`localerrordef^`、メッセージ・原因連鎖は未対応です。
- `panic^`、`with^`、`finally^`、エラー値の未使用追跡は追加していません。
- メモリ予約失敗や境界違反など、既存ランタイムの致命的診断は捕捉対象になりません。
- 合併型の選択肢に所有領域を含めることは、従来どおり禁止します。
- エラーだけの名前付き合併型は結果型の選択肢にできます。
  一方、成功とエラーが混在する名前付き合併型をさらに別の合併型の腕にした場合は、
  外側の他の腕を除外する型判定で内側の合併型へ絞り込み、名前へ束縛してから
  `try^` / `catch^` を適用します。
