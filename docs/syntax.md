# L^ の構文との対応

R^ は L^ の構文を基本とし、固定幅の型、公称構造体、借用、データスタックに必要な違いを明示します。動的テーブルは導入しません。

## ブロックと文脈付きの構築

単独のスコープは `do^{...}` と書きます。空の場合も `do^{}` です。
分岐、ループ、関数・手続き、型定義の本体は従来どおり `{...}` を使います。
`do^{...}` は文であり、値を返す式ではありません。焦点式の `for^ ... do^: ...;` とは別です。

```rhat
def^ Point { self^{ x:i32^=0,y:i32^=0 } }
let^ show=p^ point:Point { print^(point.x,point.y) }
show({x=1,y=2})
let^ point:Point={x=3,y=4}

do^{
    let^ local=Point{x=5,y=6}
    show(local)
}
```

式位置の `{field=value,...}` と `{}` は、期待される公称構造体を構築します。
引数、型付きの束縛・代入、明示された返り値型、構造体のフィールド、型付き配列の要素に適用します。
空の `{}` は既存のフィールド初期化規則を使い、必須の参照などを勝手にゼロ初期化しません。
型名付き `Point{...}` と同じ配置、既定値、公開範囲、効果、所有・寿命の検査を適用します。
モジュール外から非公開型を文脈付き構築することは許可しません。
既定のフィールド初期化は、宣言元のアクセス文脈で実行します。

期待型のない `let^ point={x=1}` や、注釈のないテンプレート引数への `{...}` は拒否します。
無名構造体型やテーブルを作る構文ではありません。
合併型に構造体の選択肢が一つだけならその型を使います。複数ある場合はフィールド名で選ばず、
`Point{...}` のような型名を要求します。エラー値も `Error.Invalid{}` と書きます。構築接頭辞の `error^` は廃止しました。
合併型の文脈では、裸の `{}` からエラー種別を暗黙に選びません。
条件式・ループ見出しの直下で構築式を書く場合は、通常の構造体と同様に `(Error.Invalid{})`
と括弧内に置きます。`if^ value fits^ Error.Invalid {` の型判定に括弧は不要です。

## 分岐・代入

```rhat
if^ value = 0 {
    print^(0)
elseif^ value < 10:
    print^(1)
else^:
    print^(2)
}

let^ sign = if^ value < 0: -1 el^ value > 0: 1 el^: 0;
```

分岐全体で波括弧は一組です。条件付きの別表記は `else^if^`、`elsif^`、`elif^`、`ei^`、`el^ condition:`。既定の腕は `else^:` または `el^:` です。式形には最後の既定の腕と終端の `;` が必要です。

`:=` に加えて `+=`、`-=`、`*=`、`/=`、`%=` を使えます。複合代入では左辺の場所と古い値を一度だけ取得します。並列代入では全左辺の場所と全右辺を取得してから書き込みます。

```rhat
var^ a,b = 1,2
a,b := b,a
a,b += 10,20
let^ ignored,value = 0,a
var^ counter := 0
```

宣言と値の個数は一致させます。右辺が式一つなら複数の返り値の分解です（[複数の返り値](results.md)）。`let^ x := ...` は認めません。`_^` は読み出せない破棄先で、繰り返して使えます。破棄した所有値もデータスタックの回収対象になります。

`a < f() <= b != c` の比較連鎖は中間値を一度だけ評価し、偽が確定したら残りを評価しません。論理演算は `and^` / `or^`、等値比較は `=` です。`==` / `&&` / `||` は式の演算子として認めません。参照型と参照取得には `ref^`、明示的な参照先アクセスには前置 `*` を使います。旧参照構文 `&T` / `&value` / `&&T` は認めません。

## ループと各節

```rhat
for^ var^ pass:i32^=0 while^ pass < 8 next^ pass += 1 {
    print^(pass)
}

for^ i from^ 1 to^ 10 step^ 2 { print^(i) }
for^ i:u8^ from^ 3 downto^ 0 { print^(i) }
for^ 2 to^ 4 { print^(it^) }

repeat^ 3 { print^(1) }
repeat^ while^ condition { work() }
repeat^ until^ finished { work() }
repeat^ { break^ }
```

単独の `while^ condition { ... }` は廃止しました。`until^` も条件を先に調べます。後判定が必要なら `pre^` で処理してから条件を調べます。

数える形は両端を含み、方向は `to^` / `downto^` で指定します。始点・終点・歩幅・`repeat^` の回数は開始時に一度だけ評価します。現段階の R^ の数える形は整数型を使います。歩幅は正である必要があり、空の範囲でも検査します。終端付近では残距離を調べ、整数の折り返しによる無限ループを防ぎます。数える形の焦点は読み取り専用です。

既存変数を使う `for^ i := 0 while^ ...`、複数焦点の `for^ var^ i=0 for^ var^ j=0 while^ ...`、カンマ区切りの更新も使えます。数える形と `repeat^` に明示的な `next^` 更新節は付けられません。

```rhat
for^ var^ i=0 while^ i<3 next^ i+=1 {
prolog^:
    var^ total=0
pre^:
    print^(i)
first^:
    var^ values:grow^ i32^[]=[]
main^:
    values.push(i)
    total+=i
last^:
    print^(i,values.len,total)
epilog^:
    print^(total)
}
```

| 節 | 実行時点 | 宣言した値の寿命 |
| --- | --- | --- |
| `prolog^` | 条件判定より前に一度 | ループ全体 |
| `pre^` | 毎回の条件判定より前。ゼロ回でも一度 | 一回の試行 |
| `first^` | 最初に条件が成立したときだけ | ループ全体 |
| `main^` | 条件が成立した各反復 | 一回の反復 |
| `last^` | 一度でも成立した場合の終了時 | 節内 |
| `epilog^` | 通常の終了時。ゼロ回でも一度 | 節内 |

節は表の順に書きます。`prologue^` / `premain^` / `epilogue^` はそれぞれ `prolog^` / `pre^` / `epilog^` の別表記です。見出しがあれば `pre^` / `first^` / `main^` / `last^` のいずれかが必要です。先頭の無見出しの本体から `last^` / `epilog^` に続けても構いません。

`last^` の焦点は最後の有効な値です。`pre^` / `main^` のローカルは終了前に回収し、`prolog^` / `first^` の値は `last^` まで保持します。`first^` の所有領域は毎回の一時領域より先に予約し、初期化は初回だけ行います。

`break^` は対象の `last^` / `epilog^` を実行します。`next^`（`skip^` / `continue^` も同義）は対象の更新に進みます。`break^^` / `break^[2]`、`next^^` / `next^[2]` で対象のループを外へ数えます。分岐・通常のブロック・マッチは段数に含めません。途中の内側ループの終了節は実行しません。`return^` は終了節を実行しません。いずれの移動でも所有領域の巻き戻しは行います。

R^ では未初期化値を読めません。ゼロ回の可能性がある `epilog^` から `first^` の値を読むこと、および `first^` の全宣言を初期化する前にそのループへ `break^` / `next^` することは現状診断します。`prolog^` / `last^` / `epilog^` から自分自身のループへ跳ぶことも現状診断します（外側のループへの多段脱出は可能です）。 現在は正の定数回数でも初期化到達の証明を行わないため、`epilog^` から `first^` の値を読むことは一律に拒否します。`pre^` と `first^` の同名宣言も現状は拒否します。

## 焦点スコープ・値マッチ

```rhat
for^ let^ n=read() if^ n>0 {
    print^(n)
else^:
    print^(0)
}

let^ twice=for^ let^ n=5 do^: n*2;
let^ answer=for^ let^ n=5 if^ n>0: n el^: 0;

for^ value {
when^ 0,1:
    print^(it^)
when^ 2 to^ 5:
    print^(2)
other^:
    print^(3)
}

let^ answer=for^ value: when^ 0: 10 when^ 1 to^ 3: 20 other^: 30;
```

マッチの対象は一度だけ評価します。腕は順に調べ、成立した一つだけを実行します。範囲の両端を含みます。現在の値マッチの対象は既存の等値・順序比較ができる型です。文字列比較や構造体の等値比較を新設したわけではありません。

### パターンマッチの網羅

`other^:`（`else^:` / `el^:` も可）を書かない**式形**のマッチは、腕が対象の値をすべて尽くしていなければなりません。尽くしたと認められるのは次の型です。

- `bool^`: `true^` と `false^` の両方を名指しする。
- [`enum^`](enums.md): すべてのメンバを `when^ Mode.Idle:` のように名指しする。
- 合併型（`nil^` との合併やエラーの合併を含む）: すべての選択肢を尽くす。選択肢は `when^ fits^ T:` で、`nil^` は `when^ nil^:` でも、
  `bool^` と `enum^` は `true^` / `false^` やメンバをすべて名指しする腕でも構いません。
  たとえば `bool^ | nil^` は `when^ true^:` / `when^ false^:` / `when^ nil^:` の 3 腕で尽くせます。

尽くしていないと、不足している値や型を示してエラーになります（`other^:` を書くか、腕を足します）。式形は値を返すので、どの型でも `other^:` か網羅が必要です。

**文形は網羅を検査しません。** 対象が enum や合併型でも、腕が当たらなければ何もせず、`other^:` は省略できます。網羅した式形で `other^:` を省いたとき、検査を通ったプログラムでは当たらない腕に `match fell through` の終了処理を置きます。

## 字句・名前

整数は `0xFF` / `0o77` / `0b1010` と数字間の `_` を使えます。浮動小数点の仮数・指数にも区切りを使えます。比較記号は `!=` / `=/` / `≠`、`<=` / `≤` / `≦`、`>=` / `≥` / `≧` を正規化します。

日本語名とバッククォート引用名を使えます。引用名内のバッククォートは二つ重ねます。空名・改行・制御文字は認めません。ハット識別子は組み込み・構文用です。通常の `bool` / `u8` などはユーザー名として使えますが、組み込み型は `bool^` / `u8^` と書きます。

`$x` / `$$x` は外側から、`$^x` / `$^^x` は現在から外側へスコープを選びます。接頭辞と名前は密着させます。暗黙の `it^` の同名焦点は `it^^` と外へ辿れます。スコープ指定は、キャプチャや別関数の実行時ローカルへのアクセスを可能にしません。

`"..."` は複数行と `\n` / `\r` / `\t` / `\0` / `\\` / `\"` / `\xHH`（`\x7F` 以下）/ `\u{...}` / 行継続を扱います。文字列リテラルは UTF-8 として正しくなければなりません。`'...'` は生文字列で、単引用符を `''` と重ねます。`"""` は行末までの生文字列です。ソースの CRLF は文字列中でも LF に正規化し、明示的な `\r` は維持します。埋め込み NUL の後ろも `.bytes` の長さ・添字・追記で保持します。

呼び出しの `(` は呼び出す値と同じ行で始めます。`return^` の値も同じ行で始めます。

## 外側の関数への呼び出し

`this^` は現在の関数の宣言、`this^^` は一つ外側、`this^^^` は二つ外側の関数の宣言を指します。
関数・手続きリテラルの入れ子だけを数えます。トップレベルの暗黙のエントリー関数は対象に含めません。

```rhat
print^(f^ n:i64^ {
    if^ n<2: 1 el^: n * f^ m:i64^ { this^^(m) }(n-1);
}(6))  # 720
```

外側の関数を新たに呼び出すための静的な指定です。外側の実行中のフレームやローカル値を捕捉せず、
必要な値は引数で渡します。型推論、テンプレート具体化、借用、効果、再帰成分の検査は通常の呼び出しと共通です。
外側に指定した深さの関数がなければ診断します。宣言が静的に決まる関数値は `let^` に束縛し、受け渡せます。
関数・手続き型の交差 `&` と演算子の `op^` は [overloads.md](overloads.md) を参照してください。

現在のメソッドへの `this^` は既存どおり self を引き継ぎます。
外側のメソッドへの `this^^` などは、受け手の参照も第一引数に明示的に渡します。

## 維持・不採用・後続の判断

| 要素 | R^ の扱い |
| --- | --- |
| `[]` | 配列リテラルとして維持 |
| `Point{field=value}` | 既知の公称構造体の構築として維持 |
| 式位置の `{...}` | 期待される公称構造体を構築。期待型がない場合は拒否 |
| `def^ C : A,B` | 既存の静的合成を維持 |
| 動的テーブル、`A .. B .. def^{...}` | 不採用。辞書型は将来の標準ライブラリで扱う |
| 数値キャスト `u8^(value)` | 維持。`as^` は追加しない |
| `do^{...}` | 単独のブロック。焦点式の `do^:` は別 |
| `fits^`、`when^ fits^ T:` | 実装済み。[適合判定・型の絞り込み](fits.md) |
| `enum^` | 実装済み。C 互換の整数列挙体で、メンバの型化・`.value` は未対応。[列挙体](enums.md) |
| `try^` / `catch^` | 実装済み。[エラー値・伝播・捕捉](errors.md) |
| `is^` | 値の同一性の規則と合わせて後続で扱う |
| `finally^` / `with^` | 所有値の後始末、途中脱出、資源型の規約が必要。今回は追加しない |
| `for^ ... in^ ...`、`index^`、コルーチン | 動的テーブルの走査は不採用。配列・辞書・利用者型を含む反復プロトコルを別途決める |
| 浮動小数点の数えるループ | 終端判定・丸め・非有限値の扱いを別途決める |
| `//` / `**` / `..` と対応する複合代入 | 固定幅整数の丸め・オーバーフロー、文字列の構築先・寿命を決めてから追加を判断 |
| UTF-8 の `string^`・`char^`・部分文字列・文字数 | 実装済み。[文字列と文字](strings.md) |
| 文字列補間 `$"..."`・Builder | 実装済み。[文字列と文字](strings.md) |
| `split`・`trim`・大文字小文字・正規化 | 未実装。[文字列と文字](strings.md) |
| 範囲の値 `range^` | 実装済み。[範囲](ranges.md)。反復への利用は未対応 |
| `?` / `?.` / `?[]` / `??` / `?:=` など | 実装済み。[合併型とニル伝播](nil.md) |
| 可変長引数 `...:T`・転送 `expr...` | 実装済み。[可変長引数とコマンド引数](variadic.md) |
| 複数の返り値 `-> (A, B)`・分解束縛 | 実装済み。エラー・`nil^` との合併を含む。[複数の返り値](results.md) |
| 関数引数の既定値 | L^ ではエディタ向け情報。実行時の省略引数としては導入しない |
| 動的ディスパッチ `ref^ dyn^ D` | 実装済み。[動的ディスパッチ](dyn.md) |
| 外側の `self^^` / `Self^^` など | 外側の受け手・型を指す規則は別途判断。`this^^` の静的な関数参照とは分けて扱う |
| 厳密なUnicode識別子の分類・正規化 | Unicode表・互換性方針を含めて別途整備する |

型の判別には `fits^` を使い、絞り込まれた値を直接利用します。エラー値、公称合併型、参照・スライス・データスタックの安全性規則は維持します。
