# 複数の返り値

関数・手続きは複数の値を返せます。引数は常に入力、出力は返り値という整理を保つためのもので、
追加の出力を受けるためだけに参照を渡す必要はありません。L^ の 13.8改 と同じく、
複数の返り値は名指せる型 `(A, B)` を持ち、書ける場所は返り値だけです。

```rhat
let^ divmod = f^ a:i64^, b:i64^ -> (i64^, i64^) {
    return^ a / b, a % b
}
let^ swap = f^ a:string^, b:string^ { b, a }   # 本体が式一つなら注釈も省ける

let^ q, r = divmod(17, 5)      # 分解束縛
var^ x, y = swap("a", "b")
x, y := swap(x, y)             # 再代入
let^ _^, rest = divmod(9, 4)   # 使わない値は _^
```

## 書き方

- 返り値の型は `-> (A, B, ...)` です。`->` の直後で、括弧の中の最上位に `,` があるときだけ複数の返り値になります。
  それ以外の括弧は今までどおり型のまとまりです（`-> (A | B)[]` など）。関数型でも `f^ i64^ -> (i64^, i64^);` と書けます。
- 返すときは `return^ a, b` です。`f^` の本体が式一つなら `f^{ a, b }` と書けます。
  返り値の注釈がなければ、返した値の型から `(A, B)` を推論します。
- `return^ g()` で、同じ型の複数の返り値をそのまま返せます。

## 受け取り

- 左辺が複数の名前で右辺が式一つなら分解束縛です。L^ と同じく印は要りません。名前の数は返り値の数と一致させます。
- 名前ごとの型注釈は書けますが、返り値の型と同じでなければなりません。
- `a, b := f()` は再代入です。複合代入（`+=` など）や `?:=` では分解しません。
- `let^ t = f()` のように一つの名前に束縛すること、引数に渡すこと（`g(f())`）、`print^` に渡すことはできません。
  値として持ち回るなら `def^` で型を宣言します。

## 実装

- `(A, B)` は要素型の並びごとに一つの無名構造体になります。フィールドの名前 `0`、`1`、... はソースから書けません。
  返り値の受け渡しは構造体と同じで、呼び出し側の構築先に書き込むか、16 バイト以下で所有値を含まなければ LLVM の値で返します。
- 分解束縛では、返り値全体を隠れた束縛で一度受け、各名前はそのフィールドを直接指します。値のコピーはありません。
  `var^` で受けた名前への書き込みは、そのフィールドへの書き込みです。
- 所有値（`grow^`・`flex^`）は構造体のフィールドと同じく、最後の一つだけに置けます。
  分解した名前は返り値全体と同じ寿命で、データスタックの回収も返り値全体として一度だけ行います。
- 所有値を返すときは、すべての `return^` が最後の値として同じローカル名を返す場合、
  そのローカルを最初から呼び出し側の構築先のフィールドに置きます（単一の返り値と同じ規則）。
  別の変数を返す `return^` が混ざると、所有値のコピーになるため拒否します。

## 境界

- `exportL^` 関数は複数の値を返せます。L^ の署名は `-> number^, number^, string^` になり、
  それぞれを L^ の値として返します。各値には単一の返り値と同じ型（数値・`bool^`・`string^`・`exportL^ def^`・
  `ref^` で渡す `exportL^ ref^ def^`）を使えます。ただし `| nil^` を含む値は C のポインタの配置にならないため、まだ使えません。
- `externC^` と `exportC^` は複数の返り値を使えません。C に対応する形がないためです。

## 未対応

- エラー・`nil^` との合併（`-> (i64^, i64^) | Error`）と、それに伴う `try^`・`catch^`・`??` の代替値 `(0, 0)`。
- ライブラリのトップレベルでの分解束縛。
