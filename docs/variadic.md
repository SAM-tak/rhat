# 可変長引数とコマンド引数

```rhat
let^ sum = f^ ...:i64^ -> i64^ {
    var^ total:i64^ = 0
    for^ var^ i:i64^ = 0 while^ i < ....len next^ i += 1 { total += ...[i] }
    return^ total
}
let^ label = f^ name:string^, ...:i64^ -> i64^ { sum(...) + ....len }
var^ values:i64^[3] = [1, 2, 3]
print(sum(), sum(1, 2, 3), label("x", 10, 20), sum(values...))   # 0 6 32 6
```

L^ と同じく、引数リストの末尾に `...:T` を置くと、固定引数を超えた引数をすべて受け取ります。
本体の中では `...` が集めた引数を指します。

## 集めた引数の型

`...` の型はスライス `T[:]` です（L^ のテーブル `t^{ T[] }` に相当）。
`....len`、`...[i]`、部分スライス `...[1 ::]` など、スライスの操作がそのまま使えます。
添字の範囲外は他のスライスと同じく実行時に診断します。

呼び出し側は、固定引数を超えた引数を自分のフレームの一時的な固定長配列 `T[N]` に組み立て、そのビューを渡します。
ヒープは使いません。引数がなければ空のスライスを渡します。
一時配列はその呼び出しを含む式の間だけ生きるため、`...` 由来の参照を戻り値で受け取った場合、
呼び出し式の中では使えますが、束縛したり return^ で持ち出したりはできません。

```rhat
let^ id = f^ ...:i32^ -> i32^[:] { return^ ... }
print(id(4, 8)[1])        # 8
let^ kept = id(4, 8)      # 拒否: reference would outlive its owner
```

要素型 `T` に所有値（`grow^ T[]` など）は使えません。参照 `...:ref^ T` は使えます。

## 転送 `expr...`

引数の後ろに `...` を書くと、その配列・スライス・`...` を相手の可変長引数へそのまま渡します。
`f(...)` のように `...` を単独で書いたときも、集めた引数の転送です。

```rhat
let^ twice = f^ xs:i64^[:] -> i64^ { sum(xs...) * 2 }
let^ depth = f^ n:i64^, ...:i64^ -> i64^ { if^ n = 0 { return^ sum(...) } return^ this^(n - 1, ...) }
```

転送する列は可変長の枠のただ一つの引数でなければなりません（`sum(1, xs...)` は未対応）。
可変長引数を持たない関数へ `expr...` は渡せません。一時的な配列リテラルは転送できないので、束縛してから転送します。

## 規則

- `...:T` は最後の引数に限り、要素型が必要です。
- 可変長の関数はオーバーロードできません。同名の関数を並べると拒否します。
- 関数値・`this^`・メソッド・`template^` でも使えます。`externC^` は可変長にできません（C の可変長関数は未対応）。
- 固定引数が足りない呼び出しは `expects at least N arguments` になります。

## コマンド引数

エントリーファイルのトップレベルは `p^ ...:string^` の本体で、`...` はプログラム名を除いたコマンド引数です。

```rhat
print(....len)
for^ var^ i:i64^ = 0 while^ i < ....len next^ i += 1 { print(...[i]) }
```

生成する `main(argc, argv)` がランタイムの `rh_runtime_args` で文字列スライスの配列を作り、エントリーへ渡します。
配列と文字列はプロセスの終了まで生きます。Windows では UTF-16 のコマンドラインを UTF-8 に変換します。
`import^` で取り込まれるモジュールのトップレベルには `...` はありません。
