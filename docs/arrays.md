# 配列の種類・スライス・範囲の表記

Goose 由来の記号による配列種別 `T[>..]` と、L^ の `slice` を引き継いだ `.slice(start, count)` を、
R^ のハット識別子と範囲表記に置き換えました。旧記法は受け付けません。
実装済みは `grow^`・`flex^`・スライスです。独立した範囲値・`step^`・`downto^` は未実装です。

## 配列の種類

種類はハット識別子で指定し、型と値で同じ語を使います。

- `T[N]`：固定長配列。修飾なしの `[a, b, c]` は従来どおり `T[3]` です。
- `grow^ T[]`：伸長のみの配列。旧記法 `T[>..]` を置き換えます。値は `grow^[a, b, c]`、空なら `grow^ T[]`（型注釈があれば `[]`）です。
- `flex^ T[]`：伸長・縮小の両方ができる配列。Goose の `T[>..<]` に相当します。値は `flex^[...]`、空なら `flex^ T[]` です。

```rhat
var^ nodes = grow^[Node{}, Node{}, Node{}]   # grow^ Node[]
var^ queue:flex^ Job[] = []
let^ make = p^ pool:ref^ grow^ Node[] -> i32^ { ... }
```

修飾は `ref^ T` と同じく前置です。`ref^ grow^ Node[]` は伸長配列全体への参照、
`grow^ (ref^ Node)[]` は参照の伸長配列です。

値の側で種類が決まるため、伸長配列でも型注釈を省けます。要素型は先頭の要素から決まり、
注釈のない空の `grow^[]` は拒否します。空の伸長配列は型名で `grow^ T[]` とも書け、
`var^ a = grow^ i64^[]` は型注釈なしで `grow^ i64^[]` 型の空配列になります。型注釈がある場合、修飾なしの `[]` / `[a, b]` は期待型の種類に従います。
`grow^` のない長さなしの `T[]` は型として拒否します。

## grow^ と flex^ の縮小

どちらも `push`・`append`・添字・スライス・`pop`・`clear`・`truncate` を持ちます。違いは縮小時の保存領域です。

- `grow^`: 縮小は論理長だけを変え、保存領域の最大末尾を配列の寿命まで保持します。既存の参照は同じスロットを指し続けるため、
  参照の扱いに制限はありません。
- `flex^`: 縮小のたびにデータスタックの先端を新しい末尾まで戻し、空いた領域が 4 MiB を超えると、
  新しい末尾の上に 1 MiB を残してページを OS に返します（Windows は `VirtualFree` の decommit、ほかは `madvise(MADV_DONTNEED)`）。
  寿命の長いキューやバッファのピーク時のメモリを、配列を破棄せずに返せます。

`flex^` の縮小は、縮める保存領域を指しうる値が残っているとコンパイルエラーです。

```rhat
var^ q:flex^ Job[] = []
let^ first = ref^ q[0]
q.pop()                      # 拒否: 'first' may refer into it
do^{ let^ r = ref^ q[0] use(r) }
q.pop()                      # 可: r のスコープは終わっている
```

- 対象はスコープ内の変数と、評価中の式で先に評価した値（前の引数・構築中のリテラルの要素）です。
- 由来と型で判定します。配列全体への参照（`ref^ flex^ T[]`）や、要素の一部になりえない型への参照は対象外です。
- 呼び出し先が引数を通じて縮める場合も同じ検査を行います。縮めるかどうかは具体化ごとの要約で、
  呼び出しを重ねても伝わります。再帰で要約が確定していない呼び出しは縮めるものとみなします。
- R^ は参照の由来をすべて追跡しているため、Goose の「内部への参照は変数にだけ置ける」という制限はありません。
  構造体や配列に入れた参照も、その変数の由来として検査されます。
- `flex^` のフィールドを持つ型は `dyn^` に変換できません（動的な呼び出しに縮小の要約がないため）。

参照の検査はスコープ単位です。最後の使用以降も、スコープが終わるまでは生存しているものとみなします。

## 範囲

- `n to^ m`：両端を含む `[n, m]`。数えるループの `to^` と同じ意味です。
- `n :: m`：終端を含まない `[n, m)`。

現在、範囲を書けるのはスライスの添字だけです。範囲を値として扱う `range^` の設計は [範囲](ranges.md) にあります。

`..` は L^ と同じく連結演算子に予約し、範囲には使いません。
`::` は R^・L^ のどちらでも未使用です。

## スライス

添字に範囲を書くと、コピーしないビュー `T[:]` を作ります。`.slice(start, count)` は廃止しました。

```rhat
let^ head = values[0 :: 3]       # 0, 1, 2
let^ tail = values[3 ::]         # 3 から末尾まで
let^ front = values[:: 3]        # 先頭から 2 まで
let^ both = values[1 to^ 3]      # 1, 2, 3
```

`a[i :: i]` は空のスライス、`a[::]` は全体です。`to^` は両端が必要です。
開始・終端は i64^ で、この順に一度だけ評価します。負の開始・開始 > 終端・範囲外は実行時に診断します。
`a[3 to^ 2]` は空です（数えるループの空範囲と同じ）。`to^` の終端 + 1 の桁あふれも範囲外になります。
`?[lo :: hi]` は `?[]` と同じく、受け手が nil なら連鎖全体を nil にします。
スライスは呼び出しではないため、それだけでは式文になりません。
固定長配列・伸長配列・スライス・文字列に使えます。文字列はバイト単位で `u8^[:]` になります。
