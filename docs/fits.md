# `fits^` と型の絞り込み

`value fits^ Type` は、値の型が右辺の型に適合するかを `bool^` で返します。
右辺は値の式ではなく型です。型注釈と同じく、組み込み型、公称型、
修飾名・インポート別名、参照、配列、スライス、合併型と括弧を使えます。
数値変換や構造的なメンバ比較は行いません。

```rhat
def^ Point { self^{ x:i32^=0 } }
var^ value:Point | i32^ | nil^ = Point{x=42}
if^ value fits^ Point {
    print(value.x)
elseif^ value fits^ i32^:
    print(value + 1)
else^:
    print(value fits^ nil^)
}
```

## 静的な判定と実行時の判定

左辺の静的な型がすべて適合する場合は真、まったく適合しない場合は偽を生成し、
実行時の型検査を生成しません。結果が決まっていても誤りにはしません。
左辺の評価は常に残すため、手続き呼び出しなどの副作用は変わりません。

合併型のうち一部だけが適合する場合は、既存のインラインのタグを調べます。
別の型記述子、ヒープ上のボックス、一般的な RTTI は追加しません。
名前付き合併型は選択肢の集合を問い、名前付き合併型を選択肢にした入れ子は
独立した値として保持します。入れ子の合併型を暗黙に再帰展開する判定は行いません。

静的合成 `def^ Derived : Base` による明示的な派生も、`Base` への適合として認めます。
絞り込みは具体的な選択肢を保持し、値を基底の配置へ切り詰めません。
複数の具体型が残る場合は合併型のままであり、共通フィールドを構造的に引く操作は追加しません。
参照は参照として判定します。`&T` と `T` を暗黙に同一視しません。

`template^` の具体化後にも同じ規則を適用します。`fits^` から静的に真偽が決まる
条件では、到達しない分岐の本体や短絡演算の右辺を具体化・生成しません。
その分岐にしかないメンバ操作を、別の具体型に要求しません。
到達する側で返却が確定する場合、後続の到達しない文も生成しません。
これは任意の定数式を評価する汎用のコンパイル時計算ではありません。

## 真側と偽側

直接の変数、および変数から `.` で辿る安定なメンバ経路を絞り込みます。
真側には適合する選択肢、偽側には残りの選択肢を渡します。
選択肢が一つになれば、その型として直接読めます。
一つも残らない側は到達しません。

`!` は真偽を反転します。`and^` の右側には左が真である情報、
`or^` の右側には左が偽である情報を渡します。
`elseif^` にも前の条件が偽である情報が累積します。

書き込みは絞り込む前の保存型に対して検査し、書き込み後に絞り込みを取り消します。
右辺を評価している間は、それ以前の有効な絞り込みを使えます。
参照を渡す変更可能な呼び出し、メソッド、配列要素の上書きにも同じ安全性検査を適用します。
別名を介した変更の可能性を追い、判断できない場合は保守的に経路の絞り込みを取り消します。
参照先のメンバの変更と、参照値そのものの変更は区別します。
メンバを書き換えても、外側の参照が存在するという有効な証明は維持します。
片方の枝の変更によって、もう片方の枝に入る時点の情報を失うことはありません。

```rhat
def^ Holder { self^{ item:Point | nil^ = nil^ } }
var^ holder = Holder{item=Point{x=7}}
if^ holder.item fits^ Point {
    print(holder.item.x)
}
```

呼び出し結果や添字アクセス自体は安定な経路として扱いません。
`f() fits^ T` や `array[i] fits^ T` は判定できますが、次に読み直した値を絞り込みません。
必要なら一度変数へ束縛します。

## ループと型パターン

`while^` の本体と `first^` では条件が真、`until^` では偽である情報を使います。
判定前の `pre^` と、終了後の `last^`・`epilog^` には条件からの絞り込みを渡しません。
ループの次の反復でも証明が成立することを検査します。
途中の `break^` があるため、ループを抜けた後に終了条件による絞り込みは残しません。

```rhat
for^ let^ result=value {
when^ fits^ Point:
    print(result.x,it^.x)
when^ fits^ i32^:
    print(result + 1)
other^:
    print("absent")
}
```

`when^ fits^ T:` は条件付きの型パターンです。`it^` と、変更されていない元の
名前付き焦点にも情報を渡します。主語の評価は一度だけです。
式形でも使用でき、従来どおり `other^:` が必要です。

比較連鎖にも `fits^` を使えます。`a < b fits^ i32^ < c` は b の適合を判定した後、
b の値を次の比較へ渡します。共有する値は一度だけ評価し、偽で短絡します。
比較連鎖全体からは変数の型を絞り込みません。

## ニル判定と参照の安全性

既存の `x?` と nil との比較も同じ分岐情報の仕組みを使います。
`if^ x? { … else^: … }` の else 側では、x は引き続き `nil^` に確定します。

型が証明できたペイロードの取り出しは、重複する実行時タグ検査を省きます。
手動の `.get(Type)` は引き続きタグを検査します。
取り出したインライン構造体・固定長配列はコピーであり、可変のペイロード参照は公開しません。
参照を選択肢にした値は、取り出した後も元の所有者の寿命を引き継ぎます。
`fits^` は借用の脱出や一時コピーへの参照を許可する演算ではありません。

`any^`、動的テーブル、構造型リテラル、関数型の値は R^ に導入していません。
それらを判定するための新しい実行時表現も今回追加しません。
